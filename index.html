怎么导出官方 ZIP？
  1. 打开 DeepSeek，进「设置」→「数据管理」
  2. 点「导出所有历史对话」，等系统准备好
  3. 复制下载链接，用浏览器打开并下载 ZIP
  4. 回到本页，点上面的「选择 ZIP 文件」
导出要等几分钟，链接有时效，下载后尽快用。App 里没看到这个入口，就用浏览器登录 deepseek.com，在设置里导出。

设置 API Key
Key 只存在这台设备的浏览器里（localStorage），不会上传，也不写进草稿。换设备、清缓存都要重填。

怎么拿 Key

  1. 打开 platform.deepseek.com，注册或登录
  2. 充值（新用户一般有免费额度）
  3. 进「API keys」，创建一个，复制 sk- 开头那串
  4. 粘到上面，点「保存」
浓缩一次通常几毛钱以内，费用从你的 DeepSeek 账户扣，和本工具无关。Key 别发给别人。
